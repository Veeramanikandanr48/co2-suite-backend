# Category 5 — Waste Generated in Operations

## 1. Purpose

Category 5 covers waste generated by the reporting organization's operations.

The collection workbook has a dedicated `S3 - Waste` form and a sewage-waste block.

## 2. Waste fields

General waste:
- Month
- Waste
- Description
- Treatment method
- Treatment process
- Unit
- Quantity
- Reference number

Sewage waste:
- Month
- Waste
- Description
- Treatment method
- Treatment process
- Unit
- Quantity
- Sewage tank capacity
- Sewage removal frequency
- Reference number

## 3. Waste master

Recommended fields:

```text
Waste Type
Treatment Method
Treatment Process
Unit
Factor
Factor Unit
Factor Source
```

## 4. Calculation

Where a mass-based factor is used:

```text
Waste mass × treatment-specific factor
```

Treatment must be part of factor selection because landfill, recycling, incineration and other treatment pathways are not interchangeable.

## 5. Sewage

Sewage should be represented as a separate waste stream because the source workbook explicitly separates it.

The application should not infer sewage quantity from tank capacity alone unless the selected methodology explicitly permits it.

## 6. Boundary and validation controls

Category 5 covers third-party disposal/treatment of waste generated in the reporting company's operations during the reporting year. Wastewater is included.

Transportation of waste by third parties may be included optionally under the GHG Protocol guidance. Therefore the application must represent transport as an explicit optional component rather than assuming that every waste factor already contains transport.

Waste treatment performed in facilities owned or controlled by the reporting organization belongs to the organization's applicable Scope 1/2 boundary rather than Category 5.

Waste-to-energy requires a dedicated double-counting control. Where waste is combusted to generate purchased electricity, the combustion treatment must not be double counted against the purchased-energy Scope 2 accounting.

Validation:
- waste type required,
- treatment method required,
- quantity required,
- unit required,
- treatment-specific factor required,
- evidence/reference required for final approval,
- facility ownership/control of the treatment site resolved,
- optional transport component identified separately.
